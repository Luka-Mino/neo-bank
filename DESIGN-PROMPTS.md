## 3. CUSTOM LOGO MARK

**Save as**: `public/images/brand/logo.svg`
**Dimensions**: 512 x 512px (must scale cleanly to 24x24)

```
Design a minimal geometric logo mark for a fintech company called "NeoBank." The logo should combine two visual concepts: a shield shape representing security and protection, and a prism or diamond shape representing innovation and the prismatic holographic brand identity. The design should merge these two shapes into a single cohesive mark — perhaps the shield silhouette has angular facets cut into it like a gemstone, or a diamond shape is nested inside a shield outline. The logo must work as a single continuous path or minimal number of paths for clean SVG rendering. It should be recognizable and legible at very small sizes (24x24 pixels) as well as large sizes. The style should be geometric, minimal, and appropriate for a financial technology company — conveying both trust and innovation. Render the logo as a solid monochrome shape in black (#000000) on a transparent background, as color will be applied later via CSS. No gradients, no shadows, no text — just the mark itself. The shape should be roughly square in proportion with a slight vertical bias. Clean, sharp edges with intentional geometric precision.
```

## 5. DOT GRID PATTERN (SVG)

**Save as**: `public/images/patterns/pattern-dots.svg`
**Dimensions**: 64 x 64px (seamless tile)

```
Create a seamless tileable SVG pattern consisting of small circular dots arranged in a perfectly regular grid layout. Each dot should be exactly 2 pixels in diameter. The dots should be spaced 16 pixels apart from center to center, both horizontally and vertically. This means in a 64x64 pixel tile, there will be 4 dots across and 4 dots down, evenly distributed. The dots should be colored in teal (#0D7366) at exactly 5% opacity, making them extremely subtle against any background color. The SVG should tile perfectly when repeated in both X and Y directions with no visible seams. The background of the SVG tile should be completely transparent. This pattern will be used as a very subtle background texture on banking app pages.
```

## 6. DIAGONAL LINES PATTERN (SVG)

**Save as**: `public/images/patterns/pattern-diagonal.svg`
**Dimensions**: 32 x 32px (seamless tile)

```
Create a seamless tileable SVG pattern consisting of thin diagonal lines running at exactly 45 degrees from bottom-left to top-right. Each line should be exactly 1 pixel wide. The lines should be spaced 8 pixels apart measured perpendicular to the line direction. The lines should be colored in teal (#0D7366) at exactly 3% opacity, making them barely perceptible as a subtle texture. The SVG should tile perfectly when repeated in both directions with no visible seams or alignment issues at the tile boundaries. Transparent background. This pattern will be used as a texture overlay on debit card surfaces and premium UI elements.
```

## 7. TOPOGRAPHIC CONTOUR PATTERN (SVG)

**Save as**: `public/images/patterns/pattern-topographic.svg`
**Dimensions**: 400 x 400px (seamless tile)

```
Create a seamless tileable SVG pattern resembling topographic map contour lines. The pattern consists of organic, smoothly flowing curved lines that never intersect each other, similar to elevation lines on a topographic map. The lines should have varying spacing between them — some areas with lines closer together and some areas more spread out, creating visual rhythm and organic flow. Each line should be exactly 0.5 pixels wide. The lines should be colored in teal (#0D7366) at exactly 4% opacity, creating an extremely subtle organic texture. The curves should flow smoothly with no sharp angles. The pattern must tile seamlessly when repeated in both X and Y directions. Transparent background. This pattern will be used as a premium background texture on hero sections and dark-themed areas of a banking app.
```
